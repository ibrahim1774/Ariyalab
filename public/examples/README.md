# Hero example clips

The homepage video rail reads `manifest.json` in this folder. It is an array of:

```json
[{ "src": "/examples/clip-1.mp4", "poster": "/examples/clip-1.jpg", "label": "Local services" }]
```

- Vertical 9:16 clips, short and looping, no sound needed (they play muted).
- Keep each file small (under about 2 MB) so the page loads fast.
- Use finished story videos you own. No logos or names that belong to someone else.
- While the array is empty, the rail shows colour placeholders labelled by business type.
